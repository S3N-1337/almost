# ALMOST — хардкорная игра на одну кнопку

Кубик бежит сам. Тап по экрану — прыжок. 10 коротких уровней (19–28 секунд).
Первые два лёгкие, дальше резко сложнее. Смерть → мгновенный рестарт и крупный процент «87%».

Работает в Telegram Mini App и в обычном браузере (на компьютере и телефоне).

---

## Как запустить на компьютере

1. Дважды кликните по файлу **`start.bat`**.
2. Откроется чёрное окно с адресами, а игра сама откроется в браузере.
3. Если Windows спросит про брандмауэр — поставьте галочку **«Частные сети»** и нажмите **«Разрешить доступ»**
   (иначе телефон не сможет подключиться).
4. Чтобы остановить игру-сервер — просто закройте чёрное окно.

Управление на компьютере: **пробел / клик мышью / стрелка вверх** — прыжок, **Esc** — пауза, **M** — звук, **R** — заново.

> Ничего устанавливать не нужно: сервер встроен в Windows (PowerShell).

## Как открыть на телефоне (тот же Wi-Fi)

1. Компьютер и телефон должны быть подключены к **одному и тому же Wi-Fi**.
2. Запустите `start.bat` на компьютере.
3. В чёрном окне найдите строку **«С телефона»** — там адрес вида `http://192.168.1.200:8080`.
4. Наберите этот адрес в браузере телефона (Chrome или Safari).

**Если на телефоне не открывается:**
- попробуйте другие адреса из окна (строка «Если не открывается…»);
- проверьте, что сеть Wi-Fi на компьютере отмечена как **частная**:
  Параметры → Сеть и Интернет → Wi-Fi → ваша сеть → «Частная сеть»;
- закройте окно `start.bat` и запустите заново — Windows ещё раз спросит про брандмауэр.

## Как проверить, что всё работает

- **Игра:** пройдите уровень 1, умрите пару раз — должен появляться крупный процент, частицы, тряска.
- **Прогресс сохраняется:** закройте вкладку и откройте снова — рекорд и открытые уровни на месте.
- **Звук:** включается после первого касания экрана (так требуют браузеры). Кнопка в правом верхнем углу — вкл/выкл.
- **Все уровни проходимы:** откройте `http://localhost:8080/tools/check.html` — там «робот» проверяет каждый уровень
  и показывает, насколько точными должны быть прыжки.
- **Посмотреть, как проходит робот:** `http://localhost:8080/?level=5&autoplay=1` (номер уровня любой).

Полезные адреса для теста:

| Адрес | Что делает |
|---|---|
| `?unlock=all` | открыть все уровни (только на этот запуск, сохранения не трогает) |
| `?level=3` | сразу запустить уровень 3 (если он открыт) |
| `?level=3&autoplay=1` | бот сам проходит уровень |
| `?fps=1` | показать FPS в углу |
| `?reset=1` | стереть весь прогресс |

## Что внутри

```
index.html          страница игры
css/style.css       оформление меню, паузы и карточки победы
js/levels.js        ← УРОВНИ (здесь добавлять новые)
js/physics.js       физика (общая для игры и проверки уровней)
js/solver.js        «робот»: проверка проходимости и автопилот
js/audio.js         звуки и музыка (Web Audio API, без файлов)
js/platform.js      Telegram: ready/expand, свайпы, вибрация, CloudStorage
js/render.js        графика: неон, частицы, тряска, вспышки
js/game.js          логика: попытки, смерть, рестарт, меню, карточка
tools/check.html    страница проверки уровней
start.bat, server.ps1   запуск локального сервера для теста
```

## Как добавить свой уровень

1. Откройте `js/levels.js` в любом текстовом редакторе (подойдёт Блокнот).
2. Скопируйте любой блок `{ ... }` уровня и вставьте в конец списка (перед `];`), не забыв запятую.
3. Нарисуйте карту символами — легенда описана в начале файла:
   `#` блок, `^` шип, `v` шип сверху, `*` батут, `o` кольцо, в нижней строке `=` земля и `_` яма.
4. Откройте `tools/check.html` — если написано «да», уровень проходим. Там же видно самые трудные прыжки.

## Telegram

Игра уже подключает Telegram WebApp SDK: вызывает `ready()` и `expand()`, отключает свайп, сворачивающий приложение,
вибрирует при прыжке и смерти, сохраняет прогресс в Telegram CloudStorage (в браузере — в localStorage),
а кнопка «Назад» Telegram ставит игру на паузу и возвращает в меню.

Чтобы открыть игру именно внутри Telegram, понадобится:
1. залить папку на хостинг с **HTTPS** (например, GitHub Pages, Netlify или Vercel — подходит «просто перетащить папку»);
2. создать бота у @BotFather и привязать к нему Mini App с этим адресом.

Это следующий шаг — бот, оплата и реклама в этой версии специально не делались.
